# Event_management

Event Management System planned for a six-member team working in parallel.

## Technology stack

- Frontend: React.js, JavaScript/JSX, Vite, React Router, Tailwind CSS.
- Backend: Python, FastAPI, SQLAlchemy, Alembic.
- Database: PostgreSQL.
- Background processing: Celery and Redis.
- Media: private S3-compatible object storage.

## Project plans

- [Implementation plan](IMPLEMENTATION_PLAN.md): architecture, domain model, delivery sequence, and validation.
- [Six-member work plan](SIX_MEMBER_WORK_PLAN.md): three frontend and three backend assignments, shared contracts, parallel checkpoints, and integration workflow.

Planning stage. Application code and runnable setup have not been created yet.
